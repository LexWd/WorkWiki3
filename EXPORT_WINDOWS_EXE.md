# 🚀 Сборка Windows Setup EXE и автообновление в 1 клик (WorkWiki 3)

В проект интегрирована конфигурация для сборки нативного десктопного приложения Windows (`Setup.exe`) на базе **Electron** и **NSIS (electron-builder)** с поддержкой фонового автообновления в 1 клик.

---

## 📦 Что вы получите на выходе

В папке `release/` после сборки формируется единый файл:

**`WorkWiki-3-Setup-2.3.1.exe`**
- **Автоматическая установка в 1 клик**: не требует прокликивания мастера установки.
- Устанавливает приложение в локальную папку пользователя (`%LOCALAPPDATA%\Programs\workwiki-3\`), не требуя прав администратора.
- Создает ярлыки на рабочем столе и в меню «Пуск».
- **Фоновое автообновление в 1 клик**: при выходе новой версии программа сама скачивает установщик, закрывает старую версию, устанавливает обновление в тихом режиме (`/S`) и сразу запускает обновленную WorkWiki 3 — полностью без вмешательства пользователя!

---

## 🖥️ Сборка на вашем компьютере Windows

1. Убедитесь, что установлен **Node.js** (версия 18, 20 или 22 с официального сайта [nodejs.org](https://nodejs.org/)).
2. Дважды кликните по файлу **`build-exe.bat`** в корне папки проекта.
3. Скрипт автоматически:
   - Установит зависимости (`npm install`)
   - Скомпилирует React и упакует приложение в Setup инсталлятор
   - Откроет папку `release/` с готовым файлом `WorkWiki-3-Setup-2.3.1.exe`

---

## ☁️ Сборка через GitHub Actions

1. Сделайте Push в ваш GitHub-репозиторий или запустите вручную в разделе **Actions** -> **Build Windows Executables**.
2. Workflow соберет актуальный `WorkWiki-3-Setup-*.exe` и прикрепит его к релизу или артефактам сборки.

---

## 🔄 Как работает 1-клик обновление в приложении

1. При нажатии кнопки **«Обновить и перезапустить в 1 клик»**:
   - Приложение создает резервную копию базы шаблонов;
   - Скачивает свежий `WorkWiki-3-Setup-*.exe` с визуальным прогресс-баром;
   - По завершении скачивания запускает фоновый тихий процесс обновления (`/S`);
   - Старый экземпляр программы завершает работу;
   - Обновленная WorkWiki 3 мгновенно открывается с сохраненными данными!
