# 🚀 Руководство по экспорту и сборке Windows EXE (QuickReply Desk)

В проект интегрирована полная конфигурация для сборки нативного десктопного приложения Windows (`.exe`) на базе **Electron** и **electron-builder**.

---

## 📦 Что вы получите на выходе

В папке `release/` после сборки будут готовы 2 типа исполняемых файлов:

1. **`QuickReply-Desk-Portable-1.0.0.exe`** (Рекомендуется для операторов)
   - Автономный исполняемый файл — не требует установки и прав администратора.
   - Можно запускать прямо с рабочего стола, из любой папки или с USB-флешки.
   - Все данные (шаблоны, базы, заметки) сохраняются локально на компьютере.

2. **`QuickReply Desk Setup 1.0.0.exe`** (Классический установщик)
   - Мастер установки в `Program Files` или `AppData`.
   - Создает ярлыки на рабочем столе и в меню «Пуск».
   - Корректная запись в «Установка и удаление программ» Windows.

## 🖥️ Вариант 1: Сборка в 1 клик на вашем компьютере Windows

### Шаг 1: Скачайте проект из Google AI Studio
1. В верхнем правом меню AI Studio нажмите значок шестеренки (или меню проекта) -> **Export to ZIP** (Экспорт в ZIP).
2. Распакуйте скачанный zip-архив в любую удобную папку на компьютере (например, `C:\Apps\QuickReplyDesk\`).

### Шаг 2: Запустите автоматический скрипт сборки
1. Убедитесь, что на компьютере установлен **Node.js** (LTS-версия: 18, 20 или 22 с официального сайта [nodejs.org](https://nodejs.org/)).
   *(Если у вас Windows 10/11, можно просто набрать в терминале `winget install OpenJS.NodeJS.LTS`)*.
2. Дважды кликните по файлу **`build-exe.bat`** в корне папки.
3. Скрипт сам:
   - Проверит окружение
   - Установит нужные пакеты (`npm install`)
   - Скомпилирует React и упакует приложение в Windows EXE
   - Автоматически откроет папку `release/` с готовыми `.exe` файлами!

## ☁️ Вариант 2: Сборка через GitHub без установки Node.js на ПК

Если у вас на рабочем компьютере нет прав администратора или вы не хотите ставить Node.js локально:

1. В меню AI Studio выберите **Export to GitHub**.
2. В репозитории уже настроен готовый GitHub Actions workflow (`.github/workflows/build-windows.yml`).
3. В вашем GitHub-репозитории перейдите во вкладку **Actions** -> выберите **Build Windows Executables** -> нажмите **Run workflow**.
4. Через 2–3 минуты в блоке **Artifacts** появится готовый архив `QuickReply-Desk-Windows-x64` с собранным `.exe` файлом, готовым к скачиванию!

## 🛠️ Ручные команды для терминала (PowerShell / CMD)

Если вы предпочитаете запускать сборку вручную из консоли:

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск в режиме живого десктопного тестирования
npm run electron:dev

# 3. Полная сборка обоих EXE (Portable + Setup)
npm run electron:build:win

# 4. Сборка только Portable EXE
npm run electron:build:portable
```

## ✨ Десктопные функции в Windows

- **Трей (Notification Area)**: Иконка приложения сворачивается в системный трей рядом с часами Windows. Двойной клик мгновенно разворачивает окно.
- **Глобальная горячая клавиша**: Нажатие `Ctrl + Alt + Q` в любой программе (в браузере, CRM, мессенджере) мгновенно поднимает QuickReply Desk на передний план поверх всех окон.
- **Закрепление поверх всех окон**: Через меню трея или настройки интерфейса окно можно зафиксировать в режиме Always-on-Top, чтобы оно не скрывалось при клике в чат клиента.
- **Запоминание размеров и позиции**: Приложение автоматически сохраняет свой размер и координаты на мониторе (включая работу с 2–3 экранами).
- **Безопасные внешние ссылки**: Все ссылки и ресурсы из базы открываются в вашем основном системном браузере (Chrome, Edge, Yandex и др.).
